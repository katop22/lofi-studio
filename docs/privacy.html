Privacy Policy

Last updated: June 7, 2026  ·  Effective immediately

Summary: Lo-Fi Studio is an open-source developer tool. We do not sell, share, or monetize any user data. We access third-party platform APIs solely to post content on behalf of the operator who configured the tool. No personal data from end-users is collected or stored.

1. Who We Are

Lo-Fi Studio ("the Application," "we," "us") is an open-source automation tool that generates lo-fi music using AI services, renders it into videos, and distributes the content to social media platforms including Pinterest, YouTube, and others. The Application is operated by its developer for personal and creative use.

Developer contact: katop22@gmail.com
Application website: https://katop22.github.io/lofi-studio/

2. Scope of This Policy

This Privacy Policy describes how Lo-Fi Studio handles data when using third-party APIs, including the Pinterest API v5. It applies to:

  • The operator of the Application (the person running the software on their own machine)
  • Any third-party platform accounts connected to the Application

This Application does not have end-users, public registrations, or a consumer-facing web service. It is a developer tool that runs locally.

3. Data We Access via the Pinterest API

When configured with a valid Pinterest access token, Lo-Fi Studio uses the Pinterest API v5 to:

  • Read boards: Retrieve the list of Pinterest boards belonging to the authenticated account, in order to select the target board for new Pins.
  • Create Pins: Post new Pins to the selected board, including an image thumbnail, title, description, and a link to the associated music video.

What data is read from Pinterest

  • Board names and board IDs of the authenticated account
  • The authenticated user's account identifier (used solely to confirm authentication)

What data is written to Pinterest

  • Pin title: an AI-generated title for the lo-fi music track
  • Pin description: an AI-generated caption describing the music
  • Pin link: a URL to the associated YouTube video
  • Pin image: a URL pointing to the AI-generated artwork for the track

4. How We Store and Protect Pinterest Data

Lo-Fi Studio stores the following Pinterest-related information locally on the operator's machine:

  • Pinterest Access Token — stored in a local .env configuration file on the operator's machine. This file is .gitignored and is never committed to any public repository.
  • Pinterest Board ID — stored in the same local .env file.
  • Pin URLs — stored in Airtable (the operator's own Airtable base) after a Pin is successfully created, for record-keeping and idempotency purposes.
We do not transmit Pinterest access tokens or board data to any server we operate. All API calls are made directly from the operator's machine to Pinterest's servers using official Pinterest API endpoints.

5. Other Third-Party Services

Lo-Fi Studio also integrates with the following services. Data handling for each is governed by that service's own privacy policy.

Airtable

Used to store track metadata, generated URLs, and posting logs. All data stored in Airtable belongs to the operator's own Airtable workspace. Privacy policy: airtable.com/privacy

YouTube (Google APIs)

Used to upload rendered music videos. Authentication is handled via Google OAuth 2.0. The Application stores only a refresh token (locally in .env). Privacy policy: policies.google.com/privacy

Suno AI

Used to generate lo-fi music tracks based on text prompts. No personal data is transmitted to Suno AI beyond the music generation prompt. Privacy policy: suno.com/privacy-policy

Ollama (local AI)

Used locally on the operator's machine to generate captions and descriptions. No data is sent to external servers. Ollama runs entirely offline.

X (Twitter)

Used to post text-only tweets. Authentication uses OAuth 1.0a tokens stored locally. Privacy policy: x.com/privacy

6. Data Retention

Lo-Fi Studio does not operate a data retention policy on behalf of third parties because it does not collect end-user data. The operator controls:

  • Local files stored on their machine (deletable at any time)
  • Records stored in their own Airtable base (deletable via Airtable)
  • Content posted to Pinterest, YouTube, and other platforms (deletable via those platforms)

7. Pinterest API Data Deletion

In compliance with Pinterest's API terms, we provide the following data deletion options:

  • Revoke access: Go to your Pinterest account settings → Security → Apps with access, and revoke Lo-Fi Studio's access. This immediately invalidates the access token.
  • Delete Pins: Any Pins created by the Application can be deleted directly from your Pinterest account at any time.
  • Request data deletion: Contact us at katop22@gmail.com and we will provide instructions to remove any stored references to your Pinterest data from the local Airtable records.

8. No Sale or Sharing of Data

We do not sell, rent, trade, or otherwise transfer any data obtained via the Pinterest API (or any other platform API) to third parties. Data accessed through platform APIs is used solely to perform the automation tasks described in this policy.

9. Children's Privacy

Lo-Fi Studio is a developer tool not intended for use by children under the age of 13. We do not knowingly collect any information from children. All content generated by the Application (lo-fi music for studying and relaxing) is suitable for general audiences.

10. Changes to This Policy

We may update this Privacy Policy from time to time. Material changes will be reflected by an updated "Last updated" date at the top of this page. Continued use of the Application after changes are posted constitutes acceptance of the revised policy.
